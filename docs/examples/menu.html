Aptus Menu CSS

Action menu ("⋯") opened from .ui-menu-trigger. On desktop it is a fixed-position popover placed next to the trigger; below 768px it opens as a bottom sheet (.ui-menu-sheet) over .ui-menu-backdrop. The positioning, keyboard and history logic belong to Palatium's ActionMenu; the small script on this page only demonstrates the CSS contract.
